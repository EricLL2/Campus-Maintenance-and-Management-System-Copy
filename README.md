# Campus-Maintenance-and-Management-System

This is the safe copy of the project CMMS. This project is contributed by LO Li-en, Chayada Pakpoomkamonlert, Joakim Bellier, Kritakorn Homsud, and Ngai Torres Pui Hong. 

The system we designed provides a comprehensive solution to manage maintenance activities, personnel, and infrastructure on the university campus. Our implementation includes a relational database backend and a Java application front-end, offering intuitive interfaces for data management, querying, and reporting.

When developing our CMMS, we employed a comprehensive software stack that supported the entire development lifecycle from database design to application implementation.
